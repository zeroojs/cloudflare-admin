# Guide Overview

This section helps first-time readers move from understanding the project to running it locally and extending it safely.

## Sections

### Getting Started

- [Quick Start](/en/guide/quick-start): boot the frontend, Worker, and docs site with the shortest path
- [Open Source](/en/guide/open-source): understand the repository layout and contribution directions

### Core Topics

- [Architecture](/en/guide/architecture): learn how Vue, Workers, KV, and Cloudflare APIs are connected
- [Auth and Permissions](/en/guide/auth-permissions): review email auth, sessions, roles, and super admin rules
- [Accounts and Zone Cache](/en/guide/accounts-zones): understand multi-account access and scheduled zone sync
- [DNS Management](/en/guide/dns-management): learn how DNS queries, edits, and batch actions are implemented
- [Mail and Security](/en/guide/mail-security): review verification emails, notifications, secrets, and password safety

### Deployment

- [Deploy to Cloudflare](/en/guide/deployment): publish the Worker, Pages site, and custom domains

## Suggested Reading Order

- For users: start with [Quick Start](/en/guide/quick-start) and [Deploy to Cloudflare](/en/guide/deployment)
- For contributors: start with [Open Source](/en/guide/open-source) and then read the core topics
- For maintainers: start with [Architecture](/en/guide/architecture) and [Mail and Security](/en/guide/mail-security)
