## Why This Project

Cloudflare Admin is designed for teams and developers who need to manage multiple Cloudflare accounts and DNS records through a single open-source control panel.

## Open-Source Repository

- GitHub: [zeroojs/cloudflare-admin](https://github.com/zeroojs/cloudflare-admin.git)
- Language switch: use the top-right language menu to move between Chinese and English docs

## Production Addresses

- Frontend: `https://cfadmin.letssl.cn/`
- API: `https://cloudflare-admin-worker-api.letssl.cn`
